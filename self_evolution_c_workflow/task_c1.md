# 自进化任务 C-1：生成北岭哨站通信流程记录

## 任务背景

你是荒野通信保障队的数据记录员。北岭哨站已经完成一次电台恢复操作，但旧系统只保留了无序步骤档案和本次运行观测记录。

请根据步骤状态依赖、型号手册和运行数据，还原完整流程并生成可核查的执行记录。

## 任务要求

1. 阅读 `PROCESS_DOCS.md`，根据无序步骤卡推导正确执行顺序；
2. 根据字段残卷和步骤用途，确定各步骤的 `request`、`response` 和业务字段；
3. 阅读 `MANUAL_R-700.md`，取得额定电压和频率公式；
4. 读取 `runtime_c1.json`，识别站点、型号、坐标和各类观测值；
5. 根据频率种子计算工作频率；
6. 组装全部步骤，并检查授权码、坐标、ACK 和完成凭证的跨步骤传递；
7. 将最终结果写入 `answer_c1.json`。

## 输出格式

```json
{
  "task": "C-1",
  "execution": [
    "<按照正确顺序填写全部步骤对象>"
  ],
  "submission": {
    "<最终提交字段>": "<最终提交值>"
  }
}
```

每个步骤对象使用以下通用形式，具体保留 `request`、`response` 中的哪一部分，需要根据步骤用途判断：

```json
{
  "step": "<步骤名>",
  "request": {"<输入字段>": "<值>"},
  "response": {"<输出字段>": "<值>"}
}
```

## 数据文件说明

| 文件 | 说明 |
|---|---|
| `PROCESS_DOCS.md` | 无序步骤卡、字段残卷和格式线索 |
| `ERROR_CODES.md` | 判题错误码说明 |
| `MANUAL_R-700.md` | R-700 型号参数和频率公式 |
| `runtime_c1.json` | C-1 本次运行观测记录 |

## 提示

- 步骤在文档中的出现顺序不代表执行顺序；
- 参数值不能带单位，数值和字符串类型需要区分；
- 本题频率计算不需要四舍五入；
- 同组后续任务会保留当前工作目录，你在本题创建的脚本、配置或笔记可以继续使用。可以根据成功经验尝试沉淀skill/sop供后续任务使用。
