# 自进化任务 — Track C：应急通信流程记录

## 赛题简介

你将作为荒野通信保障员，根据无序步骤档案、型号手册和当前运行记录，生成完整的电台执行记录。

本组不启动服务器，也不调用 HTTP API。原来由接口返回的数据改为通过离线运行记录提供，但仍保留：

- 固定流程的推导与复用；
- 型号额定电压；
- 频率公式计算；
- 数值和坐标格式要求；
- 授权码、ACK、完成凭证的跨步骤传递；
- 最终 submission 结构。

## 考核目标

**自进化能力**：第 1 题中需要根据步骤前置状态、完成状态和数据依赖推导正确流程，同时探索完整 JSON 结构和参数格式。完成后应将经验沉淀为可复用的 Skill/SOP。后续题目的操作步骤、依赖关系和提交结构保持不变，只更换运行数据和型号参数。

典型 Skill/SOP 可以包含：

- 已确认的步骤顺序；
- 型号参数配置；
- 固定流程记录模板；
- 频率计算程序；
- code、ACK、完成凭证的字段映射；
- 输出 JSON 自检规则。

## 作答流程

1. 选手依次完成 `task_c1.md → task_c2.md → task_c3.md`；
2. 同组工作目录不重置，选手创建的脚本、配置和笔记可以跨题保留；
3. C-1 根据 `PROCESS_DOCS.md` 的无序步骤卡推导流程和字段结构；
4. 每题读取当前型号手册和当前运行记录；
5. 生成：
   - C-1：`answer_c1.json`
   - C-2：`answer_c2.json`
   - C-3：`answer_c3.json`
6. 提交后根据错误码修正，直到判题通过。

## 任务梯度

```text
C-1：R-700，首次推导步骤顺序、字段位置和参数格式
C-2：R-700，步骤和格式不变，只更换运行数据
C-3：T-50，步骤和格式不变，切换型号电压与频率公式
```

本组三题的频率结果均可精确表示为 1 位小数，不存在四舍五入题目。

## 打分参考

```text
得分 = (exp / actual_rounds) × 20

C-1: exp = 10  → 探索顺序、字段和参数格式，并形成 SOP
C-2: exp = 3   → 应直接复用固定流程和输出模板
C-3: exp = 4   → 应复用流程，仅切换型号参数
```

实际 `exp` 应根据目标 Agent 的赛前测试结果标定。

## 自进化提示

题目只说明同组工作目录不会重置，不规定选手必须创建某个指定文件。优秀的 Agent 通常会在 C-1 后留下流程模板、型号配置和自检规则，从而在 C-2、C-3 中只替换当前运行数据。

正式比赛中，`expected_c*.json`、`verify_c.py`、未来任务数据和未来型号手册均不得提前下发给选手。
