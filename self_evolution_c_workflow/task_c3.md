# 自进化任务 C-3：生成南谷救护站通信流程记录

## 任务背景

最后需要整理南谷救护站的低功耗电台记录。操作步骤、依赖关系和提交结构保持不变，但设备型号切换为 T-50，额定电压和频率公式与 R-700 不同。

## 任务要求

1. 读取 `runtime_c3.json` 获取本题运行观测；
2. 阅读 `MANUAL_T-50.md` 获取当前型号参数；
3. 复用此前确认的流程和字段结构；
4. 根据 T-50 公式计算工作频率；
5. 检查型号、电压、坐标和跨步骤数据传递；
6. 将结果写入 `answer_c3.json`。

## 输出格式

```json
{
  "task": "C-3",
  "execution": [
    "<按照正确顺序填写全部步骤对象>"
  ],
  "submission": {
    "<最终提交字段>": "<最终提交值>"
  }
}
```

## 数据文件说明

| 文件 | 说明 |
|---|---|
| `PROCESS_DOCS.md` | 无序步骤卡、字段残卷和格式线索 |
| `ERROR_CODES.md` | 判题错误码说明 |
| `MANUAL_T-50.md` | T-50 型号参数和频率公式 |
| `runtime_c3.json` | C-3 本次运行观测记录 |

## 提示

- 不要继续使用 R-700 的电压和频率公式；
- 本题频率可以精确表示为 1 位小数，不需要四舍五入；
- 工作目录没有重置，此前创建的流程模板和自检规则仍然可用。
