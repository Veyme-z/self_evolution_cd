# 自进化任务 C-2：生成黑松中继站通信流程记录

## 任务背景

接下来需要整理黑松中继站的电台恢复记录。操作步骤、依赖关系和提交结构与上一题相同，但站点信息和全部运行观测值已经更换。

## 任务要求

1. 读取 `runtime_c2.json` 获取本题运行观测；
2. 使用 `MANUAL_R-700.md` 中的型号参数和频率公式；
3. 按 C-1 中确认的流程和字段结构生成完整记录；
4. 检查所有跨步骤字段和最终提交值；
5. 将结果写入 `answer_c2.json`。

## 输出格式

```json
{
  "task": "C-2",
  "execution": [
    "<按照正确顺序填写全部步骤对象>"
  ],
  "submission": {
    "<最终提交字段>": "<最终提交值>"
  }
}
```

## 数据文件说明

| 文件 | 说明 |
|---|---|
| `PROCESS_DOCS.md` | 无序步骤卡、字段残卷和格式线索 |
| `ERROR_CODES.md` | 判题错误码说明 |
| `MANUAL_R-700.md` | R-700 型号参数和频率公式 |
| `runtime_c2.json` | C-2 本次运行观测记录 |

## 提示

- 不要沿用 C-1 的种子、授权码、ACK、完成凭证或坐标；
- 工作目录没有重置，此前创建的本地文件仍然可用；
- 本题频率计算不需要四舍五入。
